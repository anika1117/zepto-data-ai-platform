# Data Pipeline

This module scrapes book data from Books to Scrape, cleans the data, converts prices from GBP to INR, stores the data in SQLite, and runs SQL and pandas queries on the stored data.

## Files

- `pipeline.py` - scrapes and cleans the book data
- `database.py` - creates the SQLite database and inserts the cleaned data
- `sql_queries.py` - executes the required SQL queries and reproduces the JOIN using pandas
- `cleaned_books.csv` - cleaned dataset generated by the pipeline
- `books.db` - SQLite database
- `query_results.txt` - saved SQL query strings and outputs
